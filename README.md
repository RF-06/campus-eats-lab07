# Campus Eats

A responsive landing page inspired by the Campus Eats Figma design.

## Run locally

From this project folder:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Files

- `index.html` – semantic page structure
- `styles.css` – responsive styling and theme tokens
- `script.js` – small interaction enhancements
- `assets/` – local copies of the Figma-exported images and SVG icons
